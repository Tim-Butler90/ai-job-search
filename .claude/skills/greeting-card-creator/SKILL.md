# Greeting Card Creator

Make a card that sounds like a real person wrote it for one specific recipient. The craft is in specificity and tone: a warm line built on a true detail beats a generic verse.

## Input requirements

Essential (ask in one short message only for what is missing):
- Recipient and relationship (for example "my sister", "a coworker retiring").
- Occasion.
- Tone (warm, funny, heartfelt, formal, playful, gentle). If unspecified, offer two directions and proceed with the safer one.

Optional:
- True personal details to include (shared memories, inside jokes, names). Use only what the user provides; never invent memories or facts about the recipient.
- Sender name and sign-off.
- Size and format (default: 5x7 in folded card, portrait, US Letter sheet for home printing).
- Brand or style preferences, language.

Sensitivity: for sympathy, illness, apology, or estrangement, keep the wording simple and sincere, avoid cheerfulness, avoid clichés like "everything happens for a reason", and avoid telling the recipient how to feel.

## Workflow

1. **Confirm the brief** in one line (recipient, occasion, tone, details). Do not ask more questions than needed.
2. **Write the copy**: front greeting (short, 3-10 words), inside message (2-5 sentences), optional back line. Offer two inside-message variants only when tone is ambiguous. No lyrics, poems, or text copied from commercial cards or books; write original wording.
3. **Write the artwork brief**: subject, style, palette, composition, where the front text sits, and what space to keep clear. Make it usable both by a human illustrator and as an image-generation prompt. If an image tool is connected and the user wants generated art, check that it is available first and say plainly whether an image was actually created. Do not claim an image exists otherwise. Do not request known characters, brands, or logos.
4. **Set dimensions** using `references/card-formats.md`: folded size, flat sheet size, fold line, trim, bleed (0.125 in), safe margin (0.25 in), and panel layout for front, inside left, inside right, back. State the numbers explicitly.
5. **Produce the file** when the user wants one: build an editable .docx or a PDF with the four panels laid out on the flat sheet (check for python-docx / reportlab / LibreOffice before use). Render and look at it. If artwork is not available, use a clean typographic design with placeholder-free layout, not fake images.
6. **Deliver** copy, artwork brief, dimensions, and the file, with a short print guide (paper weight, fold direction).

## Output format

1. Card copy (front / inside / back)
2. Artwork brief
3. Format table (folded size, flat size, bleed, safe area, fold)
4. File(s) if requested, plus print notes

## Example requests

- "Birthday card for my dad turning 70. He loves fishing and bad puns. Funny but a little sentimental."
- "A sympathy card for a coworker whose mother passed. Keep it simple."
- "Thank-you card for my kid's teacher, 5x7, printable at home."

## Quality checks

- Copy mentions only details the user supplied; nothing invented.
- Tone matches the occasion; no jokes in sympathy cards unless the user asks.
- Front text is short enough to be readable at a glance.
- Dimensions are stated numerically and add up (flat sheet = 2 x folded width; bleed and safe area given).
- Text sits inside the safe margin and away from the fold.
- Spelling and names double-checked against the brief.
- Honest status on artwork: either generated by a tool that returned success, or described in a brief for someone else to make.
