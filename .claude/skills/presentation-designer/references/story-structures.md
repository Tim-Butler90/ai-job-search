# Story structures for decks

Pick one that fits the goal. Adapt; do not force.

## Decision / ask (board, leadership, funding)
1. The ask and why now (one slide, up front)
2. The situation and the problem, with evidence
3. Options considered, with trade-offs
4. Recommendation and expected result
5. Risks and how they are handled
6. Next steps, owners, dates

## Problem - Solution - Proof (pitch, sales)
1. Problem in the customer's words
2. Why existing options fall short
3. The solution, shown simply
4. Proof (results, case, demo) with real data
5. How it works / plan
6. Ask

## Situation - Complication - Question - Answer (analysis, strategy)
1. Situation everyone agrees on
2. What changed (complication)
3. The question that creates
4. The answer, then supporting arguments (each a claim slide)

## Teach / training
1. What you will be able to do afterward
2. Concept in one picture
3. Worked example
4. Practice or check
5. Summary and where to go next

## Update / status
1. Headline: on track / at risk / off track, and why
2. Progress against plan (one chart)
3. Issues and decisions needed
4. Next period

## Rules of thumb
- Open with the point, not the agenda.
- One main point per slide; if a slide needs "and also", split it.
- Appendix holds the detail; the main deck holds the argument.
- End with the action, not "Questions?".
