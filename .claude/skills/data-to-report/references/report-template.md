# Report template (editable)

## Title and scope
One line: what this report covers, period, data source (file name), date prepared.

## Summary
3-5 bullets. Each is a finding with its number and comparison. Lead with the most important.

## Data and method
- Source file and size (rows, columns, date range)
- Data check results (missing values, duplicates, anomalies, how handled)
- Metric definitions (table: metric, formula, notes)

## Findings
For each finding:
- **Claim** (one sentence with the number)
- Chart or table
- Basis: sample size, comparison period, any caveat
- Label: Evidence / Interpretation / Assumption

## Evidence vs. assumptions
| Statement | Type | Support or what would confirm it |
|---|---|---|

## Limitations
What the data cannot tell us (coverage, missing fields, short history, possible confounders).

## Recommended next steps
Only actions the evidence supports; mark anything needing more data as "to confirm".

## Appendix
- Calculation table(s) or companion .xlsx/.csv
- Code or formulas used
- Reconciliation checks performed and their results
