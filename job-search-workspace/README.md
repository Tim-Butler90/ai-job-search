# Job Search Workspace (blank templates)

This is the folder layout the scheduled "Job Search Machine" expects. This copy is
**blank on purpose** - the repo is public, so never put resumes, contact details or
career facts here. The filled-in working copy lives in a private Google Drive folder
named `Job-Search`.

| Path | Purpose |
|---|---|
| `Resumes/` | Base resumes (Word + PDF). `Resumes/Tailored/` holds per-job versions. |
| `proof-bank.md` | Facts you confirmed, tagged CONFIRMED / LOCKED / GAP. Resume lines come only from here. |
| `WHICH-RESUME.md` | Which resume version to use for which kind of role. |
| `experience-answers.md` | Your answers to the gap questions. Moved into proof-bank.md each run. |
| `applications.csv` | One row per lead/application (status, dates, resume used, outcome). |
| `Leads/` | `radar-seen.csv`, `APPLY-QUEUE.md`, dated radar reports, `packets/` for drafts. |
| `Tools/` | `legitimacy-check.md`, `scoring-rubric.md`, `radar/` (coverage log, scripts). |
| `Plans/` | `FOLLOW-UP-CADENCE.md`. |
| `Briefs/` | Saved copies of the career intelligence briefs. |

Rules: never delete files; back up before editing; never apply or message anyone for you.
