# Follow-up cadence (default - edit freely)
- Day 0: apply on the company site. Log it in applications.csv.
- Day 3-5: short follow-up to a named recruiter/hiring manager if one is public (draft only; you send it).
- Day 10-12: one more nudge, or a note to a second contact.
- Day 21: mark "no response" and stop. Record the outcome so reply rates can be tracked.
- After any interview: thank-you within 24 hours.
